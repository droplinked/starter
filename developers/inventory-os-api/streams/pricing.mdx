---
title: "Stream 5 — Pricing"
description: "Current pricing, price history, and active promotions per SKU — write-on-mutation."
---

<Note>**BETA.** Pricing is high-churn — writes can land multiple times per minute on promotion-heavy shops. Don't attest to chain by default; pin the snapshot in your read model instead.</Note>

The **pricing stream** is the current-price-of-record per SKU plus rolling history and active
promotions. Producers: `product-v2/` and the merchant pricing UI; the dynamic-pricing engine
adds reactive writes (future). Consumers: the ACP feed, LLMS.txt, the marketplace, and the
lending underwriter's margin-signal calculation.

## Shape

```json
{
  "sku": "shop-handle__product-handle__variant-1",
  "shop_id": "65df8abc123…",
  "currency": "USD",
  "current_price": "29.99",
  "msrp": "39.99",
  "price_history": [
    { "price": "39.99", "from": "2026-05-01T00:00:00.000Z", "to": "2026-05-20T00:00:00.000Z" },
    { "price": "34.99", "from": "2026-05-20T00:00:00.000Z", "to": "2026-06-01T12:00:00.000Z" }
  ],
  "active_promotions": [
    {
      "id": "promo_2026summer",
      "type": "percent_off",
      "value": 25,
      "starts_at": "2026-06-01T00:00:00.000Z",
      "ends_at": "2026-06-30T23:59:59.000Z"
    }
  ],
  "updated_at": "2026-06-01T12:00:00.000Z"
}
```

| Field | Meaning |
|---|---|
| `current_price` | Effective sell price after active promotions |
| `msrp` | Manufacturer's suggested retail (optional) |
| `price_history[]` | Trailing 90-day price changes |
| `active_promotions[]` | Live promotions with effective windows |

## Endpoint

```
GET /developers/inventory/v1/streams/pricing
```

**Query parameters:**

| Param | Type | Notes |
|---|---|---|
| `shop_id` | string | Optional |
| `sku` | string | Optional |
| `updated_since` | ISO-8601 | Optional |
| `limit` | int | Max 200, default 50 |
| `cursor` | string | Opaque pagination token |

## curl

```bash
curl "https://apiv3.droplinked.com/developers/inventory/v1/streams/pricing?shop_id=65df8abc123" \
  -H "Authorization: Bearer ds_test_REPLACE_ME" \
  -H "X-InventoryOS-Version: 2026-06-01"
```

## TypeScript SDK

```ts
import { DroplinkedClient } from "@droplinked/sdk";

const droplinked = new DroplinkedClient({
  apiKey: process.env.DROPLINKED_API_KEY ?? "ds_test_REPLACE_ME",
});

const page = await droplinked.inventory.pricing.list({
  shopId: "65df8abc123…",
  updatedSince: new Date(Date.now() - 24 * 60 * 60 * 1000).toISOString(),
  limit: 200,
});

const onPromo = page.data.filter((row) => row.active_promotions.length > 0);
```

## Cursor pagination

```ts
let cursor: string | undefined;
do {
  const page = await droplinked.inventory.pricing.list({ cursor, limit: 200 });
  await persistPricing(page.data);
  cursor = page.next_cursor ?? undefined;
} while (cursor);
```

## Lender / margin usage

Cross-referenced with the catalog stream (1) and the sell-through stream (3), the underwriter
derives gross margin trend. Persistent discounting at >25% off MSRP across a multi-SKU shop is
flagged as a margin compression signal.

## Rate limits

Read class — 600 req/min/key. Pricing writes can be high-frequency; subscribe to
`pricing.updated` webhook events instead of polling.
