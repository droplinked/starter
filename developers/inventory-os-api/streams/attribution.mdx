<Note>**BETA.** Attribution events are real-time and high-volume. Subscribe to webhooks for live feeds; use the REST endpoint for backfills and reconciliation only.</Note>

The **attribution stream** is the affiliate-conversion record: every click, every conversion,
the publisher who drove it, the commission rule that fired, and the settlement-eligible amount.
Producers: the `/go/:linkToken` redirect, `affiliate-redirect/`, and the G1 `AffiliateProgramV2`
write log. Consumers: G5 commission rules engine, G6 analytics, G7 review queue, G10 tier
segmentation, and `affiliate-payout-settlement/`.

## Shape

```json
{
  "event_id": "evt_2qZf…",
  "event_type": "conversion",
  "link_token": "lnk_4xy…",
  "publisher_id": "pub_a1b2c3…",
  "program_id": "prog_2026spring",
  "shop_id": "65df8abc123…",
  "product_id": "shop-handle__product-handle",
  "order_id": "ord_8j7…",
  "click_at": "2026-05-31T18:22:11.000Z",
  "converted_at": "2026-06-01T11:55:42.000Z",
  "gmv": "129.00",
  "currency": "USD",
  "commission": {
    "rule_id": "rule_5x",
    "amount": "12.90",
    "currency": "USD",
    "status": "pending_review"
  },
  "attribution_window_days": 30,
  "attestation_uid": null
}
```

| Field | Meaning |
|---|---|
| `event_type` | `click` or `conversion` |
| `publisher_id` | The publisher that drove the event |
| `commission.status` | `pending_review` (G7), `approved`, `clawback`, `paid` |
| `attribution_window_days` | Window applied by the matching commission rule |
| `attestation_uid` | EAS attestation if high-value commission disputed (optional, Stream 8) |

## Endpoint

```
GET /developers/inventory/v1/streams/attribution
```

**Query parameters:**

| Param | Type | Notes |
|---|---|---|
| `publisher_id` | string | Optional |
| `program_id` | string | Optional |
| `event_type` | `click` \| `conversion` | Optional |
| `converted_since` | ISO-8601 | Optional; only conversions after timestamp |
| `commission_status` | string | Optional; filter by status |
| `limit` | int | Max 200, default 50 |
| `cursor` | string | Opaque pagination token |

## TypeScript SDK

```ts
import { DroplinkedClient } from "@droplinked/sdk";

const droplinked = new DroplinkedClient({
  apiKey: process.env.DROPLINKED_API_KEY ?? "ds_test_REPLACE_ME",
});

const page = await droplinked.inventory.attribution.list({
  eventType: "conversion",
  convertedSince: new Date(Date.now() - 24 * 60 * 60 * 1000).toISOString(),
  commissionStatus: "approved",
  limit: 200,
});

const payoutTotal = page.data.reduce(
  (acc, evt) => acc + Number(evt.commission.amount),
  0
);
```

## Cursor pagination

```ts
let cursor: string | undefined;
do {
  const page = await droplinked.inventory.attribution.list({ cursor, limit: 200 });
  await ingestEvents(page.data);
  cursor = page.next_cursor ?? undefined;
} while (cursor);
```

## Affiliate-engine usage

The attribution stream is the single source of truth for the affiliate-payout-settlement
pipeline. Combined with the settlement stream (7), payouts can be auto-released only when
PSP-confirmed and within the commission rule's attribution window. The KMS dual-approval
PayoutComplianceGate consumes this stream + Stream 7.

## Rate limits

Read class — 600 req/min/key. Conversion events are real-time; **subscribe** for live feeds
and reserve REST polling for daily reconciliation.
