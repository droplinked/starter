<Note>**BETA.** Sell-through is a derived stream — it computes off the order pipeline + 3PL `sale.confirmed` webhooks. Lag is typically &lt;1 hour.</Note>

The **sell-through stream** is the velocity record per SKU: units sold per period, GMV per
period, refund rate, and a derived velocity score. Daily rollups against a 90-day rolling
window. The lending underwriter consumes this as the cash-flow forecast input; G6 analytics and
G10 auto-tiering consume it as the affiliate-program velocity signal.

## Shape

```json
{
  "sku": "shop-handle__product-handle__variant-1",
  "shop_id": "65df8abc123…",
  "period": "2026-06-01",
  "period_type": "day",
  "units_sold": 24,
  "gmv": "2400.00",
  "currency": "USD",
  "refund_rate": 0.04,
  "velocity_score": 0.82,
  "rolling_90d": {
    "units_sold": 2148,
    "gmv": "214800.00",
    "avg_daily_units": 23.9
  },
  "computed_at": "2026-06-02T00:05:00.000Z"
}
```

| Field | Meaning |
|---|---|
| `period` | Start of rollup window (ISO date) |
| `period_type` | `day` (always, for now — week / month variants reserved) |
| `velocity_score` | 0-1 normalized velocity vs the shop's median SKU (1.0 = top quartile) |
| `rolling_90d` | Trailing 90-day aggregate, recomputed daily |
| `refund_rate` | Period refund rate (0-1); cross-reference with return-rate stream for granularity |

## Endpoint

```
GET /developers/inventory/v1/streams/sell-through
```

**Query parameters:**

| Param | Type | Notes |
|---|---|---|
| `shop_id` | string | Optional |
| `sku` | string | Optional |
| `period_start` | ISO date | Optional; rollups on/after this date |
| `period_end` | ISO date | Optional; rollups on/before this date |
| `limit` | int | Max 200, default 50 |
| `cursor` | string | Opaque pagination token |

## TypeScript SDK

```ts
import { DroplinkedClient } from "@droplinked/sdk";

const droplinked = new DroplinkedClient({
  apiKey: process.env.DROPLINKED_API_KEY ?? "ds_test_REPLACE_ME",
});

const last90 = await droplinked.inventory.sellThrough.list({
  shopId: "65df8abc123…",
  periodStart: new Date(Date.now() - 90 * 86400_000).toISOString().slice(0, 10),
  limit: 200,
});

const totalGmv90d = last90.data.reduce((acc, row) => acc + Number(row.gmv), 0);
```

## Cursor pagination

```ts
let cursor: string | undefined;
do {
  const page = await droplinked.inventory.sellThrough.list({ cursor, limit: 200 });
  await persistRollups(page.data);
  cursor = page.next_cursor ?? undefined;
} while (cursor);
```

## Lender-facing usage

Combined with Stream 4 (return rate), the underwriter derives net-revenue forecast and LGD
input. A 90-day window is typically sufficient for working-capital lines; longer windows
(180/360-day) are available on request for Tier-3 vault decisioning.

## Rate limits

Read class — 600 req/min/key. Daily-rollup volume is bounded; periodic polling (hourly) is the
standard pattern for lender integrations.
