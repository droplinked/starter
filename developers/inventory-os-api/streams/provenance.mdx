<Note>**BETA.** Provenance attestations are cryptographically anchored on-chain (Avalanche C-Chain primary + Base secondary). Once issued, an attestation UID is permanent — but the off-chain payload it references can be revoked or superseded.</Note>

The **provenance stream** is the on-chain DPP record per SKU + per inventory delta. Producers:
`multichain-attestation/` (EAS schema registration + attestation emit), `crawler/` (Crossmint
dispatch). Consumers: ACP feed, LLMS.txt, the marketplace, the lending underwriter
(highest-trust signal — 0-50 bps off rate), the compliance gate, and the buyer-side trust
badge.

## Shape

```json
{
  "attestation_uid": "0xabc123ef456…",
  "schema_uid": "0xschemAUID0987…",
  "sku": "shop-handle__product-handle__variant-1",
  "shop_id": "65df8abc123…",
  "product_hash": "0x4f8a…",
  "attester": "0xDeployerWalletAddress…",
  "chain": "avalanche-c-chain",
  "chain_id": 43114,
  "block_number": 47891234,
  "transaction_hash": "0xtxhash…",
  "attested_at": "2026-06-01T12:00:00.000Z",
  "valid_until": null,
  "revoked": false,
  "ipfs_cid": "bafybei…",
  "mirror": {
    "chain": "base",
    "chain_id": 8453,
    "attestation_uid": "0xmirrorUID…"
  }
}
```

| Field | Meaning |
|---|---|
| `attestation_uid` | EAS attestation UID (chain-scoped) |
| `schema_uid` | EAS schema UID — the schema this attestation conforms to |
| `product_hash` | SHA-256 of canonical product JSON (deterministic; from Stream 1) |
| `chain` / `chain_id` | Primary attestation chain — Avalanche C-Chain or Base |
| `valid_until` | Optional expiry; `null` = perpetual |
| `revoked` | True if attester has revoked |
| `ipfs_cid` | Off-chain payload (e.g. full DPP document) on IPFS |
| `mirror` | Cross-chain mirror attestation (when issued) |

## Endpoint

```
GET /developers/inventory/v1/streams/provenance
```

**Query parameters:**

| Param | Type | Notes |
|---|---|---|
| `shop_id` | string | Optional |
| `sku` | string | Optional |
| `chain` | `avalanche-c-chain` \| `base` | Optional |
| `attested_since` | ISO-8601 | Optional |
| `include_revoked` | bool | Default `false` |
| `limit` | int | Max 200, default 50 |
| `cursor` | string | Opaque pagination token |

## Verification

Provenance attestations can be independently verified on-chain. Look up the UID against the
EAS contract on the named chain — Droplinked does not need to be online for verification.
This is the cryptographic-unforgeability property that gives this stream the highest trust
weight in the lender signal hierarchy.

```ts
import { ethers } from "ethers";

const eas = new ethers.Contract(
  "0xEASContractAddress",
  ["function getAttestation(bytes32 uid) view returns (tuple(...))"],
  new ethers.JsonRpcProvider("https://api.avax.network/ext/bc/C/rpc")
);

const onchain = await eas.getAttestation("0xabc123ef456…");
```

## Lender-facing usage

The cryptographically-unforgeable property is what unlocks the 0-50 bps off the lending rate.
Combined with PSP-confirmed settlement (Stream 7) and 3PL custody (Stream 2), the underwriter
operates at investment-grade LGD. This is the data-fusion outcome the lending platform was
designed around.

## Rate limits

Read class — 600 req/min/key. Attestation emission is debounced (60s) per inventory delta;
polling frequency should match that cadence.
